# COU-R-SPP-四-可以-简便方式公开规则

> **来源**: [[小型个人信息处理者个人信息保护简化措施规定]]
> **条款**: 第四条第二款
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 小型个人信息处理者 |
| 动作 | 可以 |
| 客体 | 线下收集通过在经营场所醒目位置张贴公告等简便方式公开处理规则；线上收集通过服务协议、客户端弹窗和网站公告等方式公开处理规则 |
| 条件 | 线下/线上收集个人信息公开处理规则时 |
| 权重计算 | 8 × 1.0 = **8.0** |

## 原文

> 小型个人信息处理者线下收集个人信息的，可以通过在经营场所醒目位置张贴公告等简便方式公开个人信息处理规则；线上收集个人信息的，可以通过服务协议、产品服务客户端弹窗和网站公告等方式公开个人信息处理规则。
