# COU-R-SPP-十-可以-省级网信评估建议

> **来源**: [[小型个人信息处理者个人信息保护简化措施规定]]
> **条款**: 第十条第四款
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 所在地省级网信部门 |
| 动作 | 可以 |
| 客体 | 形成评估结论建议并报国家网信部门核准 |
| 条件 | 小型个人信息处理者确需向境外提供个人信息，依法申请数据出境安全评估时 |
| 权重计算 | 8 × 1.0 = **8.0** |

## 原文

> 小型个人信息处理者确需向中华人民共和国境外提供个人信息，依法向网信部门申请数据出境安全评估的，可以由所在地省级网信部门形成评估结论建议并报国家网信部门核准。
