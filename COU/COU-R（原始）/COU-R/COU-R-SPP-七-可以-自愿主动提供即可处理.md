# COU-R-SPP-七-可以-自愿主动提供即可处理

> **来源**: [[小型个人信息处理者个人信息保护简化措施规定]]
> **条款**: 第七条第一款
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 小型个人信息处理者 |
| 动作 | 可以 |
| 客体 | 按照公开的个人信息处理规则处理个人信息 |
| 条件 | 公开处理规则并履行告知义务后，个人因获取产品或服务需要，在充分知情前提下自愿、主动提供或配合提供所必需的个人信息 |
| 权重计算 | 8 × 1.0 = **8.0** |

## 原文

> 小型个人信息处理者公开个人信息处理规则并履行告知义务后，个人因获取产品或者服务需要，在充分知情的前提下自愿、主动向或者自愿、主动配合小型个人信息处理者提供获取产品或者服务所必需的个人信息的，小型个人信息处理者即可按照公开的个人信息处理规则处理其个人信息。
