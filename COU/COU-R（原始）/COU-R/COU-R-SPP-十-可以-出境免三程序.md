# COU-R-SPP-十-可以-出境免三程序

> **来源**: [[小型个人信息处理者个人信息保护简化措施规定]]
> **条款**: 第十条第一款
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 小型个人信息处理者 |
| 动作 | 可以/免予 |
| 客体 | 符合条件之一的，免予申报数据出境安全评估、订立个人信息出境标准合同、通过个人信息保护认证 |
| 条件 | （一）订立履行个人作为一方当事人的合同确需出境；（二）跨境人力资源管理确需出境；（三）紧急情况保护生命健康财产安全；（四）履行法定职责或法定义务；（五）当年累计向境外提供不满10万人个人信息（不含敏感个人信息）；（六）其他规定条件 |
| 权重计算 | 8 × 1.0 = **8.0** |

## 原文

> 小型个人信息处理者向境外提供个人信息，符合下列条件之一的，免予申报数据出境安全评估、订立个人信息标准合同、通过个人信息保护认证：（一）为订立、履行个人作为一方当事人的合同……确需向境外提供个人信息的；（二）按照依法制定的劳动规章制度和依法签订的集体合同实施跨境人力资源管理……；（三）紧急情况下为保护自然人的生命健康和财产安全……；（四）为履行法定职责或者法定义务……；（五）关键信息基础设施运营者以外的个人信息处理者自当年1月1日起累计向境外提供不满10万人个人信息（不含敏感个人信息）的；（六）法律、行政法规或者国家网信部门规定的其他条件。
