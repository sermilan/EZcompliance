# COU-R-SPP-十六-应当-立即补救并通知

> **来源**: [[小型个人信息处理者个人信息保护简化措施规定]]
> **条款**: 第十六条
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 小型个人信息处理者 |
| 动作 | 应当 |
| 客体 | 立即采取补救措施，依照法律、行政法规规定通知个人，并按照规定通知履行个人信息保护职责的部门 |
| 条件 | 发生或者可能发生个人信息泄露、篡改、丢失时 |
| 权重计算 | 8 × 1.5 = **12.0** |

## 原文

> 发生或者可能发生个人信息泄露、篡改、丢失的，小型个人信息处理者应当立即采取补救措施，依照法律、行政法规规定通知个人……并按照规定通知履行个人信息保护职责的部门。
