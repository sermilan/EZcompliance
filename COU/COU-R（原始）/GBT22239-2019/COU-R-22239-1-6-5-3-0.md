# COU-R-22239-1-6-5-3-0

> **来源**: [[GBT 22239-2019]]
> **章节**: 第1级 - 安全区域边界 - 6.5.3(6.5.3)
> **层级**: R (原始COU · Raw)
> **基础权重**: 6.4

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 部署 |
| 客体 | 访问控制设备，配置访问控制策略，禁止任何穿越区域边界的 E-Mail、Web、Telnet、Rlog... |
| 条件 | 定级为第1级时 |
| 权重计算 | 6.4 × 1.3 = **8.3** |

## 原文

> 应在工业控制系统与企业其他系统之间部署访问控制设备，配置访问控制策略，禁止任何穿越区域边界的 E-Mail、Web、Telnet、Rlogin、FTP 等通用网络服务。
