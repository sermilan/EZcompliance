# COU-R-22239-5-5-2-5-0

> **来源**: [[GBT 22239-2008]]
> **章节**: 第5级 - 系统运维管理 - 5.2.5(5.2.5)
> **层级**: R (原始COU · Raw)
> **基础权重**: 10.4

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 进行 |
| 客体 | 病毒检查，对外来计算机或存储设备接入网络系统之前也应进行病毒检查 |
| 条件 | 定级为第5级时 |
| 权重计算 | 10.4 × 1.3 = **13.5** |

## 原文

> 应提高所有用户的防病毒意识，告知及时升级防病毒软件，在读取移动存储设备上的数据以及网络上接收文件或邮件之前，先进行病毒检查，对外来计算机或存储设备接入网络系统之前也应进行病毒检查。
