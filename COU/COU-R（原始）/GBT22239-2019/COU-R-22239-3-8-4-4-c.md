# COU-R-22239-3-8-4-4-c

> **来源**: [[GBT 22239-2019]]
> **章节**: 第3级 - 安全运维管理 - 8.4.4(c)
> **层级**: R (原始COU · Raw)
> **基础权重**: 9.6

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 部署 |

| 条件 | 定级为第3级时 |
| 权重计算 | 9.6 × 1.3 = **12.5** |

## 原文

> 应加强对感知节点设备、网关节点设备部署环境的保密性管理，包括负责检查和维护的人员调离工作岗位应立即交还相关检查工具和检查维护记录等。
