# COU-R-60003-3-3-3-（1

> **来源**: [[2021版网络安全等级保护测评师]]
> **章节**: 第3级 - 入侵防范 - 3.3(（1)
> **层级**: R (原始COU · Raw)
> **基础权重**: 9.6

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 部署 |
| 客体 | 了具有入侵防范功能的设备。如果部署了相应的设备，则检查设备的日志记录，查看其中是否记录了攻击源IP地... |
| 条件 | 定级为第3级时 |
| 权重计算 | 9.6 × 1.3 = **12.5** |

## 原文

> 访谈网络管理员和查看网络拓扑结构，核查在网络边界处是否部署了具有入侵防范功能的设备。如果部署了相应的设备，则检查设备的日志记录，查看其中是否记录了攻击源IP地址、攻击类型、攻击目的、攻击时间等信息，了解设备采用何种方式进行报警。
