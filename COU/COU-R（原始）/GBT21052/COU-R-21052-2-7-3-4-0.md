# COU-R-21052-2-7-3-4-0

> **来源**: [[GBT 21052-2007]]
> **章节**: 第2级 - 设备管理 - 7.3.4(7.3.4)
> **层级**: R (原始COU · Raw)
> **基础权重**: 8.0

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 执行 |
| 客体 | 管理功能的授权管理员和可信主机与使用物理设备的所有其他个人或系统分开 |
| 条件 | 定级为第2级时 |
| 权重计算 | 8.0 × 1.3 = **10.4** |

## 原文

> 应只允许授权管理员和可信主机承担安全管理职责。应能把授权执行管理功能的授权管理员和可信主机与使用物理设备的所有其他个人或系统分开。
