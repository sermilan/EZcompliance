# COU-R-21052-1-6-3-6-0

> **来源**: [[GBT 21052-2007]]
> **章节**: 第1级 - 资源利用 - 6.3.6(6.3.6)
> **层级**: R (原始COU · Raw)
> **基础权重**: 6.4

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 建立 |
| 客体 | 配额或其他方式，来定义代表某个特定用户或主体进行分配的资源空间大小或时间长短的限制 |
| 条件 | 定级为第1级时 |
| 权重计算 | 6.4 × 1.3 = **8.3** |

## 原文

> 应通过控制用户和客体对资源的占用，使得不因不恰当地占有资源而出现拒绝服务情况。资源分配规则允许通过建立配额或其他方式，来定义代表某个特定用户或主体进行分配的资源空间大小或时间长短的限制。
