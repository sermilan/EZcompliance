# COU-R-NSRA-七-应当-委托

> **来源**: [[网络数据安全风险评估办法]]
> **条款**: 第七条应当-委托
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章层级)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络数据处理者 |
| 动作 | 应当 |
| 客体 | 委托评估机构开展风险评估时，通过订立合同或者其他具有法律效力的文件等方式明确双方权利、义务 |
| 条件 | 委托评估机构开展风险评估时 |
