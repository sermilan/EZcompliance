# COU-R-28448-2-7-2-3-8

> **来源**: [[GBT 28448-2018]]
> **章节**: 第2级 - 安全区域边界 - 7.2.3(8)
> **层级**: R (原始COU · Raw)
> **基础权重**: 8.0

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 记录 |
| 客体 | 相应的攻击行为，攻击行为日志记录是否包含攻击类型、攻击时间、攻击者IP和攻击流量规模等内容 |
| 条件 | 定级为第2级时 |
| 权重计算 | 8.0 × 1.3 = **10.4** |

## 原文

> 通过对外攻击发生器伪造对外攻击行为，核查云租户的网络攻击日志，确认是否正确记录相应的攻击行为，攻击行为日志记录是否包含攻击类型、攻击时间、攻击者IP和攻击流量规模等内容；
