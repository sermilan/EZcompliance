# COU-R-28448-2-7-2-3-3

> **来源**: [[GBT 28448-2018]]
> **章节**: 第2级 - 安全区域边界 - 7.2.3(3)
> **层级**: R (原始COU · Raw)
> **基础权重**: 8.0

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 部署 |

| 条件 | 定级为第2级时 |
| 权重计算 | 8.0 × 1.3 = **10.4** |

## 原文

> 应核查部署的抗 APT 攻击系统、网络入侵保护系统等入侵防范设备或相关组件是否具备异常流量、大规模攻击流量、高级持续性攻击的检测功能，以及报警功能和清洗处置功能；
