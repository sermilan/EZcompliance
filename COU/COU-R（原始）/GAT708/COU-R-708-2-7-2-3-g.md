# COU-R-708-2-7-2-3-g

> **来源**: [[GAT 708-2007]]
> **章节**: 第2级 - 运行管理分等级要求 - 7.2.3(g)
> **层级**: R (原始COU · Raw)
> **基础权重**: 8.0

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 进行 |
| 客体 | 详细说明。信息安全系统的运行管理者，应按照文档的要求，进行风险管理 |
| 条件 | 定级为第2级时 |
| 权重计算 | 8.0 × 1.3 = **10.4** |

## 原文

> 风险管理：信息安全系统的设计者，应按7.2.2 g）的要求，根据不同安全等级的需要，明确不同安全等级的风险管理的要求，从信息收集和信息分析等方面，以文档形式对风险管理的要求进行详细说明。信息安全系统的运行管理者，应按照文档的要求，进行风险管理；
