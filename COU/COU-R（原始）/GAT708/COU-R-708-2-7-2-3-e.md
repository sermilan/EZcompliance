# COU-R-708-2-7-2-3-e

> **来源**: [[GAT 708-2007]]
> **章节**: 第2级 - 运行管理分等级要求 - 7.2.3(e)
> **层级**: R (原始COU · Raw)
> **基础权重**: 8.0

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 进行 |
| 客体 | 详细说明。信息安全系统的运行管理者，应按照文档的要求，对相关人员进行严格的培训、考核与操作管理 |
| 条件 | 定级为第2级时 |
| 权重计算 | 8.0 × 1.3 = **10.4** |

## 原文

> 人员培训、考核与操作管理：信息安全系统的设计者，应按7.2.2 e）的要求，根据不同安全等级的需要，明确不同安全等级的培训、考核与操作管理要求，从对人员的培训、考核及操作管理等方面，以文档形式进行详细说明。信息安全系统的运行管理者，应按照文档的要求，对相关人员进行严格的培训、考核与操作管理；
