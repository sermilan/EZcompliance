# COU-R-SPP-十三-可以-五年合规审计

> **来源**: [[小型个人信息处理者个人信息保护简化措施规定]]
> **条款**: 第十三条第一款
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 小型个人信息处理者 |
| 动作 | 可以 |
| 客体 | 按照附件《合规审计自查表》的简便方式，至少每五年开展一次个人信息保护合规审计，并保存合规审计自查表至少五年 |
| 条件 | 开展个人信息保护合规审计时 |
| 权重计算 | 8 × 1.0 = **8.0** |

## 原文

> 小型个人信息处理者可以按照本规定附件《小型个人信息处理者个人信息保护合规审计自查表》的简便方式，至少每五年开展一次个人信息保护合规审计，并保存合规审计自查表至少五年。
