# COU-R-SPP-八-可以-不再重复审计评估

> **来源**: [[小型个人信息处理者个人信息保护简化措施规定]]
> **条款**: 第八条第二款
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 小型个人信息处理者 |
| 动作 | 可以 |
| 客体 | 不再重复开展个人信息保护合规审计、个人信息保护影响评估 |
| 条件 | 符合第八条第一款条件，且网络平台已开展合规审计、影响评估并覆盖其依托平台开展的处理活动 |
| 权重计算 | 8 × 1.0 = **8.0** |

## 原文

> 符合前款规定条件的，网络平台已开展个人信息保护合规审计、个人信息保护影响评估，覆盖小型个人信息处理者依托该网络平台开展的个人信息处理活动的，小型个人信息处理者可以不再重复开展。
