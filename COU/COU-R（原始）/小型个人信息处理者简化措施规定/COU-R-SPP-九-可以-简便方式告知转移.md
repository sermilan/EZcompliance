# COU-R-SPP-九-可以-简便方式告知转移

> **来源**: [[小型个人信息处理者个人信息保护简化措施规定]]
> **条款**: 第九条第一款
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 小型个人信息处理者 |
| 动作 | 可以 |
| 客体 | 通过在经营场所醒目位置张贴公告、短信提醒等简便方式告知接收方的名称或者姓名以及联系方式；依托网络平台的可通过平台内经营者页面公告、小程序公告等方式告知 |
| 条件 | 因合并、分立、解散、被宣告破产等原因需要转移个人信息时 |
| 权重计算 | 8 × 1.0 = **8.0** |

## 原文

> 小型个人信息处理者因合并、分立、解散、被宣告破产等原因需要转移个人信息的，可以通过在经营场所醒目位置张贴公告、短信提醒等简便方式告知接收方的名称或者姓名以及联系方式……依托网络平台提供产品或者服务的，可以通过其在网络平台内的经营者页面公告、小程序公告等方式告知。
