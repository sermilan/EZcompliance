# COU-R-SPP-八-可以-依托平台免规则告知

> **来源**: [[小型个人信息处理者个人信息保护简化措施规定]]
> **条款**: 第八条第一款
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 小型个人信息处理者 |
| 动作 | 可以 |
| 客体 | 不再制定个人信息处理规则、履行告知义务 |

| 权重计算 | 8 × 1.0 = **8.0** |

## 原文

> 同时符合下列条件的小型个人信息处理者，可以不再制定个人信息处理规则、履行告知义务：（一）仅通过网络平台开展个人信息处理活动，且不向网络平台外的其他个人信息处理者提供；（二）网络平台已制定发布相应的个人信息处理规则并约定各自权利和义务；（三）声明遵守平台规则，处理个人信息为提供产品或者服务所必需，未超出规则载明范围。
