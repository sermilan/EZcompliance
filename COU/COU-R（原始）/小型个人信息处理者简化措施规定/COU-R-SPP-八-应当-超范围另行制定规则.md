# COU-R-SPP-八-应当-超范围另行制定规则

> **来源**: [[小型个人信息处理者个人信息保护简化措施规定]]
> **条款**: 第八条第三款
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 小型个人信息处理者 |
| 动作 | 应当 |
| 客体 | 另行制定个人信息处理规则并履行告知、合规审计和影响评估义务 |
| 条件 | 处理个人信息的目的、方式和种类超出网络平台个人信息处理规则范围时 |
| 权重计算 | 8 × 1.5 = **12.0** |

## 原文

> 小型个人信息处理者处理个人信息的目的、处理方式和种类超出网络平台个人信息处理规则范围的，应当按照本规定要求另行制定个人信息处理规则并履行告知、合规审计和影响评估义务。
