# COU-R-SPP-五-支持-园区统一规则

> **来源**: [[小型个人信息处理者个人信息保护简化措施规定]]
> **条款**: 第五条第一款
> **层级**: R (原始COU · Raw)
> **基础权重**: 8 (部门规章)

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 园区、产业基地、商业物业等服务管理单位 |
| 动作 | 支持 |
| 客体 | 为服务管理范围内开展相同线下业务的小型个人信息处理者统一制定并在显著位置公开个人信息处理规则 |
| 条件 | 服务管理范围内有开展相同线下业务的小型处理者 |
| 权重计算 | 8 × 0.7 = **5.6** |

## 原文

> 支持园区、产业基地、商业物业等服务管理单位，为其服务管理范围内开展相同线下业务的小型个人信息处理者统一制定并在显著位置公开个人信息处理规则。
