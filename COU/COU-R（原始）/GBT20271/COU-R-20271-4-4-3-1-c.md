# COU-R-20271-4-4-3-1-c

> **来源**: [[GBT 20271-2006]]
> **章节**: 第4级 - 身份鉴别 - 4.3.1(c)
> **层级**: R (原始COU · Raw)
> **基础权重**: 10.4

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 确定 |
| 客体 | 系统中的某些操作是否由同一用户引起 |
| 条件 | 定级为第4级时 |
| 权重计算 | 10.4 × 1.3 = **13.5** |

## 原文

> 不可关联性：一个用户可以多次使用资源和服务，但任何人都不能将这些使用联系在一起，即：应确保任何用户和/主体不能确定系统中的某些操作是否由同一用户引起；
