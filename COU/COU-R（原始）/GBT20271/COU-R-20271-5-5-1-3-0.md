# COU-R-20271-5-5-1-3-0

> **来源**: [[GBT 20271-2006]]
> **章节**: 第5级 - SSF 数据安全保护 - 5.1.3(5.1.3)
> **层级**: R (原始COU · Raw)
> **基础权重**: 10.4

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |

| 客体 | 一条可信的数据传输信道，保护通信数据免遭修改和泄漏，同时应允许由 SSF 或远程信息系统的 SSF ... |
| 条件 | 定级为第5级时 |
| 权重计算 | 10.4 × 1.3 = **13.5** |

## 原文

> 应在 SSF 与远程信息系统的 SSF 之间提供一条可信的数据传输信道，保护通信数据免遭修改和泄漏，同时应允许由 SSF 或远程信息系统的 SSF 原发的经可信信道的通信，支持由可信信道功能列表所列各种功能原发的经可信信道的通信。
