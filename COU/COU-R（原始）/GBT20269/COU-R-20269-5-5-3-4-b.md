# COU-R-20269-5-5-3-4-b

> **来源**: [[GBT 20269-2006]]
> **章节**: 第5级 - 基于风险的决策 - 5.3.4(b)
> **层级**: R (原始COU · Raw)
> **基础权重**: 10.4

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 采取 |
| 客体 | 相应的风险规避和监测控制措施，并明确风险一旦发生的责任陈述 |
| 条件 | 定级为第5级时 |
| 权重计算 | 10.4 × 1.3 = **13.5** |

## 原文

> 信息系统受控运行：在 a）的基础上，如果信息系统的残余风险不可接受，而现实情况又要求系统必须投入运行，且当前没有其它资源能胜任组织机构的使命，经过组织机构管理层的审批，可以临时批准信息系统投入运行，同时应采取相应的风险规避和监测控制措施，并明确风险一旦发生的责任陈述。
