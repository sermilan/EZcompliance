# COU-R-20269-5-5-5-5-c

> **来源**: [[GBT 20269-2006]]
> **章节**: 第5级 - 有关安全机制保障 - 5.5.5(c)
> **层级**: R (原始COU · Raw)
> **基础权重**: 10.4

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 定期 |
| 客体 | 统一升级、统一控制，紧急情况下增加升级次数；对检测或截获的各种高风险病毒进行及时分析处理，提供相应的... |
| 条件 | 定级为第5级时 |
| 权重计算 | 10.4 × 1.3 = **13.5** |

## 原文

> 基于集中实施的病毒防护管理：在 b）的基础上，实行整体网络统一策略、定期统一升级、统一控制，紧急情况下增加升级次数；对检测或截获的各种高风险病毒进行及时分析处理，提供相应的报表和总结汇报；采取对系统所有终端有效防范病毒或恶意代码引入的措施；
