# COU-R-39204-3-8-2-d

> **来源**: [[GB T 39204-2022]]
> **章节**: 第3级 - 方式和内容 - 8.2(d)
> **层级**: R (原始COU · Raw)
> **基础权重**: 9.6

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 进行 |
| 客体 | 检测评估，分析关键业务链以及关键资产等方面的变更，评估上述变更给关键信息基础设施带来的风险变化情况，... |
| 条件 | 定级为第3级时 |
| 权重计算 | 9.6 × 1.3 = **12.5** |

## 原文

> 在关键信息基础设施发生改建、扩建、所有人变更等较大变化时，应自行或者委托网络安全服务机构进行检测评估，分析关键业务链以及关键资产等方面的变更，评估上述变更给关键信息基础设施带来的风险变化情况，并依据风险变化以及发现的安全问题进行有效整改后方可上线；
