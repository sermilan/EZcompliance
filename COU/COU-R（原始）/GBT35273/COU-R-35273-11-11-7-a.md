# COU-R-35273-11-11-7-a

> **来源**: [[GBT 35273-2020]]
> **章节**: 第11级 - 安全审计 - 11.7(a)
> **层级**: R (原始COU · Raw)
> **基础权重**: 8.0

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 提供 |
| 客体 | 扩展业务功能及所必要收集的个人信息，并允许个人信息主体对扩展业务功能逐项选择同意 |
| 条件 | 定级为第11级时 |
| 权重计算 | 8.0 × 1.3 = **10.4** |

## 原文

> 在扩展业务功能首次使用前，应通过交互界面或设计（如弹窗、文字说明、填写框、提示条、提示音等形式），向个人信息主体逐一告知所提供扩展业务功能及所必要收集的个人信息，并允许个人信息主体对扩展业务功能逐项选择同意；
