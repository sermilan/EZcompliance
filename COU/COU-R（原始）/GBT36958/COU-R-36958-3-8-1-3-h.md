# COU-R-36958-3-8-1-3-h

> **来源**: [[GBT 36958-2018]]
> **章节**: 第3级 - 审计管理要求 - 8.1.3(h)
> **层级**: R (原始COU · Raw)
> **基础权重**: 9.6

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 进行 |
| 客体 | 审计，应通过运维审计系统对管理员的运维行为进行安全审计；应通过租户隔离机制，确保审计数据隔离的有效性 |
| 条件 | 定级为第3级时 |
| 权重计算 | 9.6 × 1.3 = **12.5** |

## 原文

> 在云计算平台中，应对云服务器、云数据库、云存储等云服务的创建、删除等操作行为进行审计，应通过运维审计系统对管理员的运维行为进行安全审计；应通过租户隔离机制，确保审计数据隔离的有效性；
