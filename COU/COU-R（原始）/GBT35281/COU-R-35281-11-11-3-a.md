# COU-R-35281-11-11-3-a

> **来源**: [[GB／T 35281-2017]]
> **章节**: 第11级 - 安全审计 - 11.3(a)
> **层级**: R (原始COU · Raw)
> **基础权重**: 8.0

## 解剖结构

| 要素 | 内容 |
|------|------|
| 主体 | 网络安全等级保护对象运营者 |
| 动作 | 定期 |
| 客体 | 对日志进行安全审计，及时发现并调查日志中的异常事件 |
| 条件 | 定级为第11级时 |
| 权重计算 | 8.0 × 1.3 = **10.4** |

## 原文

> 应为移动互联网应用服务器运行及维护状况留存日志，必要时可使用专用的日志服务器保存日志信息，以防止服务器遭受攻击后日志被篡改。服务器的运营者应定期对日志进行安全审计，及时发现并调查日志中的异常事件。
