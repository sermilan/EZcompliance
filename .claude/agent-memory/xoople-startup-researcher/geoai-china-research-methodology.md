# GeoAI中国市场调研方法论

## 研究框架

### 1. 信息获取策略
- **WebFetch优先**：直接抓取权威页面（新浪财经、搜狐科技、官方政策网站）
- **多源交叉验证**：市场规模数据需2-3个独立来源确认
- **搜索工具降级**：MCP搜索失败时用WebSearch，WebSearch失败时用WebFetch直接抓URL

### 2. 核心数据来源优先级
1. 官方政策文件（民航局、自然资源部等）
2. 权威媒体财经报道（新浪财经、36氪、央视新闻）
3. 行业协会报告（赛迪顾问、中国地理信息产业协会）
4. 公司官方渠道（官网、招股书、投资者互动）
5. 第三方数据库（IT桔子、Crunchbase，仅作为融资数据参考）

### 3. 关键评估维度（GeoAI垂直场景）
- TAM/SAM/SOM估算
- 客户付费意愿和CAC
- 数据获取壁垒（涉密/开放/半开放）
- 国家队vs民营资本格局
- 政策依赖度

## 关键发现：中国GeoAI市场特点

### 数据管制等级
| 等级 | 数据类型 | 创业可用性 |
|------|----------|------------|
| 涉密 | <0.5m光学/<1m SAR | 不可用，需国家队资质 |
| 管制 | 高分辨率国产卫星 | 需申请，流程长 |
| 开放 | Landsat/Sentinel/16m平台数据 | 可用，主流农业遥感数据源 |

### 国家队主导领域
- 遥感数据源：长光卫星、航天宏图、中科星图
- 气象数据：气象局体系
- 低空经济监管：民航局体系

### 民营创业机会窗口
- 农业遥感+AI：数据层开放，算法层有机会
- 低空服务层：监管外的服务层
- 垂直行业工具：不做平台做应用
