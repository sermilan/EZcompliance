# 每日回顾

## 1. 读取日历信息

读取以下日历文件（如存在）：
- `Inbox（收件箱）/日历.md`
- `Inbox（收件箱）/calendar.md`
- 或任何包含今日日程的笔记

## 2. 读取任务列表

读取以下任务文件（如存在）：
- `Inbox（收件箱）/任务.md`
- `Inbox（收件箱）/tasks.md`
- `Inbox（收件箱）/待办.md`
- 或任何包含任务列表的笔记

## 3. 读取消息摘要

读取以下消息文件（如存在）：
- `Inbox（收件箱）/消息.md`
- `Inbox（收件箱）/messages.md`
- 或任何包含未读消息/待回复的笔记

## 4. 读取过去一周的每日笔记

扫描以下模式的每日笔记：
- `Inbox（收件箱）/YYYY-MM-DD.md`（过去 7 天）
- `Inbox（收件箱）/每日笔记/YYYY-MM-DD.md`

按日期倒序读取最近 7 天的每日笔记，提取：
- 已完成事项
- 未完成事项
- 待跟进项目
- 新想法/灵感

## 5. 生成当日计划

综合以上信息，按以下格式生成报告：

```markdown
# 📅 今日计划 — [日期]

## ⭐ 优先事项（最多 3 项）
1. [最重要的事 + 原因]
2. [第二优先]
3. [第三优先]

## 📅 今日日程
- [时间] [事件]
- ...

## 📋 待办任务
- [ ] [任务描述]
- ...

## 💬 待回复消息
- [发送人] — [简要内容]
- ...

## 🔗 来自过去一周的待跟进
- [从每日笔记中提取的未完成事项]

## 💡 今日灵感
- [从每日笔记中提取的新想法]
```

## 输出要求

- 根据可用信息生成报告
- 如果某些信息不存在，跳过该部分
- 使用 Emoji 增强可读性
- 优先事项应基于任务紧急程度和上下文重要性排序
