# 场景：监管检查与协同

> **来源**: 网络数据安全风险评估办法 (联合令第24号)
> **涉及 COU 数量**: 12
> **适用主体**: 有关主管部门、国家网信部门、省级以上有关部门

## 场景概述

覆盖监管侧从工作机制建立、年度检查计划统筹、行业评估组织到跨部门信息共享与投诉举报受理的全方位监管协同体系。

## 关联 COU

### 工作机制与顶层设计 (第3·4条)

- [[COU-R-NSRA-三]] — 国家网信部门会同电信、公安等建立网络数据安全风险评估专项工作机制 (w=8.0)
- [[COU-R-NSRA-四-应当]] — 有关主管部门按照"谁管业务、谁管业务数据、谁管数据安全"原则定期组织本行业风险评估 (w=12.0)
- [[COU-R-NSRA-四-应当-检查]] — 根据工作需要对本行业重要数据处理者评估情况进行检查 (w=12.0)
- [[COU-R-NSRA-四-应当-报送计划]] — 每年1月底前将年度风险评估检查计划报送国家网信部门 (w=12.0)
- [[COU-R-NSRA-四-共享与协调]] — 国家网信部门通过协调机制将计划与电信、公安、国安共享协调，避免不必要检查和交叉重复 (w=12.0)
- [[COU-R-NSRA-四-不得]] — 检查不得向被检查的重要数据处理者收取费用 (w=4.0)

### 风险信息共享与协同处置 (第20条)

- [[COU-R-NSRA-二十-应当-共享]] — 有关主管部门应当加强风险信息共享和协同处置 (w=12.0)
- [[COU-R-NSRA-二十-应当-报告]] — 应当按照有关规定及时报告风险评估中发现的重大安全风险和问题 (w=12.0)

### 社会监督 (第21条)

- [[COU-R-NSRA-二十一-有权]] — 任何组织、个人有权对风险评估中的违法活动向有关部门投诉举报 (w=8.0)
- [[COU-R-NSRA-二十一-应当-处理]] — 收到投诉举报的部门应当依法及时处理 (w=12.0)

## 监管时间线

```
每年1月底前  主管部门报送年度检查计划
    │
    ▼
  全年持续   组织行业评估 + 检查重要数据处理者
    │
    ▼
  实时      收到报告后10个工作日内通报网信部门
    │
    ▼
  实时      风险信息跨部门共享 + 协同处置
```

## 合规要点

1. **检查统筹**：国家网信部门统一协调，避免多头重复检查
2. **免费原则**：检查不得收费
3. **计划公开**：每年1月底前完成检查计划报送与共享
4. **投诉畅通**：任何组织个人均可举报违法评估活动
