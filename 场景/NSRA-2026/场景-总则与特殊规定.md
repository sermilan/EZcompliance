# 场景：总则与特殊规定

> **来源**: 网络数据安全风险评估办法 (联合令第24号)
> **涉及 COU 数量**: 9
> **适用主体**: 所有网络数据处理者

## 场景概述

覆盖办法的立法目的、适用范围、术语定义、评估依据，以及核心数据、商用密码、涉密信息等特殊情形的衔接规定。

## 关联 COU

### 总则 (第1·2条)

- [[COU-R-NSRA-一]] — 立法目的：规范网络数据安全风险评估活动，保障网络数据安全，促进数据依法合理有效利用 (w=8.0)
- [[COU-R-NSRA-二-应当]] — 在中华人民共和国境内开展网络数据安全风险评估应当遵守本办法 (w=12.0)
- [[COU-R-NSRA-二-定义]] — 网络数据安全风险评估是指对网络数据和网络数据处理活动安全进行的风险识别、风险分析和风险评价 (w=8.0)

### 特殊情形衔接 (第23·24条)

- [[COU-R-NSRA-二十三-按照]] — 处理核心数据的网络数据处理者的风险评估按国家有关规定执行 (w=6.4)
- [[COU-R-NSRA-二十三-应当-密码]] — 涉及重要数据加密等技术措施的，应按商用密码法律法规要求开展商用密码应用安全性评估 (w=12.0)
- [[COU-R-NSRA-二十四-按照]] — 涉及国家秘密、工作秘密的风险评估活动按保守国家秘密法等执行 (w=6.4)

### 施行 (第25条)

- [[COU-R-NSRA-二十五-信息]] — 本办法自2026年8月20日起施行 (w=8.0)

## 关键判定

| 数据类型 | 适用规则 |
|----------|---------|
| 重要数据 | 本办法全文适用 |
| 一般数据 | 鼓励性适用（第5条） |
| 核心数据 | 按国家有关规定执行（不直接适用本办法） |
| 涉及加密技术 | 叠加商用密码应用安全性评估 |
| 涉及国家秘密 | 按保密法规执行（本办法排除适用） |

## 合规要点

1. **适用范围确认**：境内所有网络数据安全风险评估活动均受管辖
2. **数据分级判定**：首先确认自身处理的数据属于核心/重要/一般哪一级
3. **加密叠加**：涉及密码技术的须同步完成密评
4. **保密优先**：涉密场景以保密法为准，本办法退位
