# 场景：违规处置与罚则

> **来源**: 网络数据安全风险评估办法 (联合令第24号)
> **涉及 COU 数量**: 4
> **适用主体**: 有关部门、重要数据处理者、评估机构

## 场景概述

当发现网络数据处理者未按规定开展风险评估、评估机构违反办法，或重要数据处理活动可能危害国家安全和公共利益时，监管部门的处置权限及罚则。

## 关联 COU

### 责令整改与加重处置 (第19条)

- [[COU-R-NSRA-十九-应当-整改]] — 有关部门发现重要数据处理者的重要数据处理活动可能危害国家安全、公共利益的，应当依据职责责令整改 (w=12.0)
- [[COU-R-NSRA-十九-可以-停止处理]] — 对拒不整改或未达到整改要求的重要数据处理者，可以采取要求其停止处理重要数据等措施 (w=8.0)

### 法律责任追究 (第22条)

- [[COU-R-NSRA-二十二-应当-处理]] — 发现网络数据处理者未按规定开展风险评估的，依据《数据安全法》《网络数据安全管理条例》等予以处理 (w=12.0)
- [[COU-R-NSRA-二十二-应当-处罚机构]] — 发现评估机构违反本办法的，依法予以处理 (w=12.0)

## 处置升级路径

```
发现违规
    │
    ▼
[数据处理者未评估] 或 [评估机构违规]
    │
    ▼
依据上位法处理 (第22条)
    ║
    ║
[重要数据处理活动危害国安/公益]
    │
    ▼
责令整改 (第19条)
    │
    ├── 整改达标 → 结案
    │
    └── 拒不整改/未达标
            │
            ▼
        停止处理重要数据 ⚠️ 最严厉措施
```

## 合规要点

1. **双重追责**：数据处理者和评估机构均有独立罚则
2. **上位法衔接**：罚则主要依据《数据安全法》和《网络数据安全管理条例》
3. **渐进处置**：先责令整改 → 拒不整改才采取停止处理措施
4. **最重后果**：停止处理重要数据——可直接导致业务停摆
