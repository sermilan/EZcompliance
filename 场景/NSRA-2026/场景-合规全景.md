# 场景：合规全景

> **来源**: 网络数据安全风险评估办法 (联合令第24号)
> **涉及 COU 数量**: 54（全覆盖）
> **覆盖主体**: 重要数据处理者、一般数据处理者、核心数据处理者、评估机构、有关主管部门、国家网信部门、省级以上有关部门、任何组织/个人

## 场景概述

以重要数据处理者年度评估为主线的全景视图，串联全部6个子场景。

## 主体视角合规路径

### 路径一：重要数据处理者（红色高合规路径）

```
年初 ──▶ 确认评估方式（自行/委托）──▶ 签订合同/指定专人
  │                                        │
  ▼                                        ▼
开展年度评估 ←── 参照国标/主管部门规定 ←── 选任评估机构（轮换检查≤3次）
  │
  ▼
编制评估报告 ──▶ 报告保存（≥3年）
  │
  ▼
20个工作日内报送主管部门
  │
  ├── 主管部门明确 ──▶ 报送
  └── 主管部门不明确 ──▶ 报送省级/国家网信部门
  │
  ▼
配合核验检查
  │
  ├── 正常 ──▶ 年度合规完成
  │
  ├── 触发强制评估 ──▶ 委托已认证机构 ──▶ 限时完成 ──▶ 双签盖章报送 ──▶ 整改 ──▶ 15日报整改报告
  │
  └── 违规 ──▶ 责令整改 ──▶ 拒不整改 ──▶ 停止处理重要数据
```

### 路径二：评估机构（紫色合规路径）

```
接受委托 ──▶ 签订合同
  │
  ├── 不得转委托
  ├── 连续服务同客户≤3次
  ├── 公正客观评估
  │
  ▼
出具报告（真实性·有效性·完整性负责）
  │
  ├── 发现重大风险 ──▶ 即时通知数据处理者
  │
  ▼
评估结束 ──▶ 保密 ──▶ 删除/妥善处置信息
```

### 路径三：监管侧（蓝色监管路径）

```
年初 ──▶ 制定检查计划 ──▶ 1月底前报送网信部门
  │
  ▼
网信部门协调共享（避免交叉重复）
  │
  ▼
全年 ──▶ 组织行业评估 + 检查重要数据处理者
  │         │
  │         ▼
  │      收到报告后10工作日通报网信部门
  │         │
  │         ▼
  │      网信部门汇总 → 工信部/公安部/国安共享
  │
  ▼
发现违规 ──▶ 依法处理（数据安全法·网数管理条例）
```
