前  言

政府数据 核心元数据 第2部分：法人单位基础数据

1. 范围

本标准规定了贵阳市政府数据法人单位核心元数据和数据元素的相关概念、元数据属性的描述以及数据元素目录。

本标准适用于政府数据集和数据集系列的编目和描述、数据集和数据集系列的组织管理，也可用于数据交换中心的数据服务。

1. 规范性引用文件

下列文件对于本文件的应用是必不可少的。凡是注日期的引用文件，仅所注日期的版本适用于本文件。凡是不注日期的引用文件，其最新版本（包括所有的修改单）适用于本文件。

1. 术语和定义
   1. 法人 Iegal person

具有民事权利能力和民事行为能力，依法独立有民事权利和承担民事义务的组织。

[GB/T 20091-2006，2.1]

* 1. 组织机构 organization

企业、事业单位、机关、社会团体及其他依法成立的单位的通称。

[GB/T 20091-2006，2.2]

1. 数据元素表示规范和目录
   1. 表示规范

本标准采用摘要表示的方式定义和描述数据元素，包括以下几个属性：名称、汉语拼音缩写、说明、数据类型、数据格式、注释。

* + 1. 中文名称

数据元素的中文名称。

* + 1. 内部标识符

一个数据元素的唯一内部标识符。

* + 1. 中文全拼

数据元素的中文名称的汉语拼音。

* + 1. 汉语拼音缩写

数据元素的中文名称的汉语拼音缩写。

* + 1. 说明

数据元素的解释。

* + 1. 语境

一个名称所用于的或所源自的应用环境或规程的描述。

[GB/T 19488.1-2004，3.13]

* + 1. 对象类词

描述对象集的词语。

* + 1. 特性词

描述对象类的所有个体所共有的某种性质的词语。

* + 1. 表示词

值域、数据类型的组合，必要时也包括计量单位或字符集。

[GB/T 18391.1-2002，3.60]

* + 1. 数据类型

一些可区分的值的集合，这种区别由这些值的性质以及对这些值的运算所表征。

[GB/T 18221-2000，4.11]

* + - 1. 字符型 string

通过字符形式表达的值的类型。

* + - 1. 数值型 number

通过可计算的十进制形式表达的值的类型。

* + - 1. 日期型 date

通过CCYYMMDD的形式表达的值的类型，符合 GB/T 7408-2005 规定。

* + 1. 数据格式

数据元素值的表示格式。表示格式如表1。

1. 数据元素表示格式表

|  |  |
| --- | --- |
| 字符 | 含义 |
| C | 表示数据类型为字符型 |
| N | 表示数据类型为数字型 |
| D | 表示数据类型为日期型 |
| ..UL | 表示长度不定的文本 |
| .. | 从最小长度到最大长度，前面附加最小长度，后面附加最大长度。允许只附加最大长度。 |
| N..p,q | 表示数据类型为数值型，最长p位，小数点后q位（小数点前p－q位）。 |
| 注1： 用C或N加上自然数的方式表示定长。  注2： 用D加4，6，8分别表示不同数据格式的日期型数据元，D4表示CCYY，D6表示CCYYMM；D8表示CCYYMMDD。 | |

* + 1. 值域

允许值的集合。

* + 1. 备注
    2. 注释

对该数据元的其他相关说明，包括需要遵守的标准和规范。

中文名称：变更信息

内部标识符：

中文全拼：bian-geng-xin-xi

汉语拼音缩写：BGXX

说明：组织机构基本情况的变更记录，包括变更事项、变更日期等信息。

数据类型：字符型

数据格式：C..200

值域：

备注：

注释：变更信息通过数据库的动态维护保证。

1. 数据约束
   1. 经营或业务范围

选择主要经营或业务范围内容进行录入，内容中的拉丁字母，必须是半角拉丁字母。

* 1. 代码录入

组织机构代码、组织机构类型代码、经济行业代码、经济类型代码、行政区划代码、注册号或登记号中含有的拉丁字母，必须是半角大写拉丁字母。

* 1. 变更信息

参照“变更日期|变更事项|变更前内容|变更后内容”格式录入。
