# 总则

**第1条** 为规范安徽移动业务支撑系统和管理信息化系统中对于设备及系统软件巡检操作流程和规范，特制定本管理办法。

**第2条** 本管理流程为业务支撑系统和管理信息化系统内设备及系统软件巡检提供依据。

**第3条** 巡检工作由省信息系统部完成，分工如下：

1、IT基础设施室主机管理员负责业务支撑系统和管理信息化系统中主机、存储、备份系统以及卷管理、双机、同步等系统软件的巡检工作；

2、IT基础设施室数据库和中间件管理员负责业务支撑系统和管理信息化系统中数据库系统、中间件系统巡检工作；

3、IT基础设施室网络管理员负责业务支撑系统和管理信息化系统中网络设备系统巡检工作；

4、IT基础设施室安全管理员负责业务支撑系统和管理信息化系统中安全设备系统巡检工作；

**第4条** 本管理办法解释权和修改权归省公司信息系统部，每年复审一次，其它时候也可根据需要进行修订并发布。

# 适用范围

**第5条** 本管理流程适用于业务支撑系统和管理信息化系统，即NGBOSS、BOSS容灾系统、经营分析系统、客服系统、电子化渠道、ITIL电子流、PMOS、VGOP系统、PBOSS、以及采集系统和管理信息化系统，即统一门户系统、OA系统、ERP系统、PMS系统、银企报账系统、合同管理系统。

**第6条** 本办法适用于所有和上述系统合同设备中主机、存储、网络、安全、备份设备、采集和操作系统、集群、卷管理、同步软件、数据库和中间件系统软件巡检管理。

# 巡检操作流程

为规范巡检工作，使巡检工作有序的进行，巡检工作需按照以下流程操作：

**第7条** 巡检工作根据维保合同按每季度或每月执行（节假日巡检可与季度巡检一并完成，如5月1日、10月1日、春节等），除例行巡检外，还应按照系统运行情况执行固定频次的巡检。

**第8条** 信息系统部各专业巡检厂商按要求执行日、周、月作业计划，按照作业计划模板的内容，仔细检查系统的运行状况，对系统存在的问题进行仔细分析，提出解决问题的建议，排除系统中存在的问题，在作业计划规定时间内在bomc系统提交巡检作业计划报告。作业计划完成报告由系统管理员审阅（通过电子方式）并存档。巡检中未发现问题则关闭流程，如发现问题，根据《安徽移动业务支撑系统问题处理实施细则》的规定解决问题。

# 巡检人员职责

本管理办法的执行人包括系统管理员和巡检厂商，相关职责如下：

**第9条** IT基础设施室的各系统管理员负责制定作业计划规则和协同巡检厂商进行巡检工作，审核巡检厂商的巡检报告。

**第10条** 巡检厂商负责对系统进行仔细、彻底的检查，检查系统存在的问题，提出解决问题的建议，杜绝系统存在的隐患，编写厂商巡检报告(巡检报告内容包括但不限于：巡检范围、系统现状、巡检发现的问题以及建议的解决措施)。

**第11条** 巡检厂商应按时保质完成BOMC系统生成的巡检作业计划；各系统管理对厂商巡检情况进程监督检查考核，以保证巡检质量。

# 巡检工作内容

巡检工作根据巡检对象的不同分为主机、存储、网络、安全、带库、数据库、中间件、备份和系统软件（卷管理、双机、同步）9个方面。厂商的巡检工作必须包括但不局限于“巡检工作内容”。各个专业巡检工作内容见附件2。

# 问责管理

**第12 条** 违反本管理办法，有下列情形之一并对公司造成重大损失的，应对相关责任人给予相应处罚：

（一）巡检厂商未按照作业计划模板和在规定时间执行巡检、巡检过程中未检查出系统明显存在的隐患、对系统存在的问题分析不清、解决问题的建议不能排除系统隐患；

（二）各系统管理员不按照质量考核条款对巡检厂商进行扣分扣款。

**第13条** 信息系统部将定期对各专业管理情况执行情况进行抽查，对于违反以上规定的，要限期整改，并给予通报批评。

**第14** **条**  凡违反本管理办法规定，给企业造成经济损失和重大影响的，依据《中国移动通信集团公司员工违纪违规处分条例（试行）》相关规定和当年签订维保合同厂商质量考核条款，追究有关人员或责任厂商的责任。
